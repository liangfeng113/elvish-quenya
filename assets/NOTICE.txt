espeak-ng（昆雅发音用的语音引擎）
================================

本项目 assets/espeak/ 下包含：

  libespeak_ng.dll                         eSpeak NG 1.52.0 的 Windows 运行库
  espeak-ng-data/                          语音数据（含昆雅音素数据 qya / qya_dict）

来源：https://github.com/espeak-ng/espeak-ng  （release 1.52.0 的 espeak-ng.msi，解出后使用）

许可：GPLv3（GNU General Public License version 3）
      https://www.gnu.org/licenses/gpl-3.0.html
      完整条款见 https://github.com/espeak-ng/espeak-ng/blob/master/COPYING

本项目对 espeak-ng 的用法：不修改其源码或数据，仅以 ctypes 动态加载 DLL 调用其公开 API
（espeak_Initialize / espeak_SetVoiceByName / espeak_Synth 等），并通过 app/speech.py 包装。
本项目的其余部分（词库工具、课程、界面）不是 espeak-ng 的衍生作品。
